## Ownership and numbering

Проектные ADR используют следующий свободный четырёхзначный номер, начиная с
`0001`. Номера удалённых или отклонённых решений повторно не используются.
Принятые записи не переписываются задним числом: изменение решения оформляется
новым ADR с указанием supersession.
